# Changelog

## 0.1.0

1. feat(probe) Sample CPU, memory, temperatures, network traffic, and disk I/O on Linux.
2. feat(services) Track memory usage by systemd service.
3. feat(history) Keep up to 90 days of history on each monitored machine.
4. feat(hub) Collect probe histories and serve a dashboard for multiple machines.
5. feat(security) Encrypt and authenticate probe connections with per-device keys.
6. feat(sync) Backfill missing history when a probe reconnects to the hub.
7. feat(dashboard) Browse live and historical charts by machine and time range.
8. feat(build) Run as static Linux binaries on x86-64, ARM64, and ARMv6 or later.
